# Dédal des Couleurs

Site vitrine responsive de la galerie d'art Dédal des Couleurs.

## Pages
- `index.html` : accueil
- `galerie.html` : présentation de la galerie
- `oeuvres.html` : collection avec filtres Peinture / Sculpture
- `visite.html` : exposition et informations pratiques

## Lancer le site
Ouvrir `index.html` dans un navigateur, ou utiliser l'extension Live Server de VS Code.

## Publication GitHub Pages
Dans le dépôt GitHub : Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## À vérifier avant publication
- Remplacer les polices de secours par les fichiers officiels Kitchakan et HK Grotesk si disponibles.
- Vérifier les informations pratiques et les coordonnées auprès de la galerie.
- Le formulaire newsletter est une démonstration front-end : il ne collecte ni n'envoie réellement les adresses.
- Les textes et visuels des œuvres reprennent les éléments fournis dans les maquettes et documents du projet.
